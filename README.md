## Cel projektu

Celem projektu jest stworzenie "pożyczalni" prywatnych samochodów. Czyli aplikacji, której użytkownicy pożyczają samochody innym użytkownikom.

### Podstawowe funkcjonalności

- Tworzenie kont
- Wstawianie ofert wynajmu swoich własnych samochodów
- Akceptowanie ofert innych użytkowników

### Funkcjonalności dodatkowe

- Wystawianie ocen użytkownikom
- System reputacji
- System potwierdzania tożsamości

## Technologie

- Front-end: React
- Back-end: SpringBoot
- Relacyjna baza danych MySQL
