# Google Api setup instruction

Set environment variables on Windows:

```powershell
# PowerShell
$env:CLIENT_ID="current_client_id"

# CMD
set CLIENT_ID=current_client_id
```

Set environment variables on Linux:

```bash
# Temporary (current session)
export CLIENT_ID="current_client_id"

# Permanent (bash)
echo 'export CLIENT_ID="current_client_id"' >> ~/.bashrc
source ~/.bashrc
```
